# 落魄神明

成為詭異世界嘅落魄神明。開局只剩一個信徒喺神像前不斷膜拜（每拜一次 +1 神力）；儲夠神力就召喚「現實玩家」，佢哋以為呢度係 VR 遊戲副本，敢死亂衝、瘋狂試錯——但喺呢度，死咗就真係冇咗。

- **神殿**：信徒即時膜拜賺神力；安排人手膜拜、生產、清潔、守衛；召喚玩家、睇墓碑
- **新手村**（村長身份）：低難度新手任務
- **冒險者公會**（櫃台職員身份）：高危委託
- **攻略 Wiki**：玩家每次試錯都會累積攻略，死者遺言最有用

完成任務後由你決定分幾多賞金俾玩家：分得越多佢哋升級越快、士氣越高；留低嘅就係你嘅信仰。神格去到 100 會出現主線「奪回空白神座」，打贏就通關；詭異值到 100 就輸。

單一 HTML 檔，直接打開 `index.html` 就玩得。

## 角色
- 召喚係抽卡：**C 55% / R 30% / SR 12% / SSR 3%**，稀有度決定六維範圍、技能同能力數量
- **六維**：力量、敏捷、體質、智力、感知、幸運（撳名睇角色卡雷達圖，可以用神力逐點加）
- **技能**（任務用）：挑釁、爆發、治癒術、閃避、偵察、背刺、不死身、鼓舞、速攻、掠奪
- **能力**（工作／被動）：種田達人、潔癖、夜眼、狂信、學霸、吸金體質、再生、鐵胃、天選之人
- 死咗嘅角色會變墓碑，撳墓碑可以用神力復活
